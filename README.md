# Electricity Bill Calculator

### CIE-2 Activity-6 – OOP GUI Application

A Java Swing-based Electricity Bill Calculator that calculates electricity bills based on the number of units consumed by a customer. This project demonstrates Java GUI programming, OOP concepts, event handling, and input validation.

## Features

- Simple and user-friendly GUI.
- Customer name input.

## How to Run

1. Install JDK on your computer.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Open the terminal.
5. Compile the program:

```bash
javac ElectricityBillCalculator.java
```

6. Run the program:

```bash
java ElectricityBillCalculator
```
